# CERTICOS BOOKS
프론트 사전과제
카카오 Daum 책 검색 API를 이용해 도서를 찾고 관심 있는 책을 저장하는 웹입니다. 제공된 디자인 이미지의 검색 화면, 상세검색 팝업, 도서 상세 아코디언, 찜 목록을 구현했습니다.

## 실행 방법

Node.js 24.14.1을 기준으로 개발했습니다. nvm이 없다면 Node.js 24.14.1을 직접 설치한 뒤 `npm ci`를 실행합니다. nvm을 사용하는 경우 프로젝트 루트에서 아래 명령을 실행하면 `.nvmrc`에 지정된 버전이 적용됩니다.

```bash
nvm install
nvm use
```

의존성을 설치합니다.

```bash
npm ci
```

제출 이메일에 첨부된 `.env` 파일을 프로젝트 루트에 놓고 실행합니다. REST API 키는 Next.js 서버에서 카카오에 요청할 때 사용합니다.

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다.

```bash
npm run typecheck
npm run build
```

## 기술 선택

- **Next.js App Router**는 UI와 서버 API를 한 프로젝트에서 관리할 수 있어 선택했습니다.
- **React와 TypeScript**로 공통 도서 행을 구성하고, 검색 파라미터와 API 응답의 타입을 공유합니다.
- **React Query**는 검색어, 검색 조건, 페이지를 기준으로 결과를 캐시합니다. 요청에 취소 신호를 전달하고 로딩, 오류, 재시도 상태를 처리합니다.
- **상태 관리**는 데이터의 역할에 따라 나눴습니다. API 검색 결과는 React Query로 관리하고, 현재 탭과 펼친 도서 등 화면 상태는 `useState`로 관리합니다. 최근 검색어와 찜 목록은 새로고침 후에도 유지되도록 `localStorage`에 저장합니다.
- **CSS와 Lucide**로 레이아웃, 테마, 조작 아이콘을 구성했습니다.

## 주요 기능

- Enter로 일반 검색을 실행하고 최근 검색어를 최대 8개까지 저장합니다. 최근 검색어는 개별 삭제하거나 다시 검색 할 수 있습니다.
- 제목, 저자명, 출판사로 상세검색할 수 있습니다. 일반 검색과 상세검색은 각각 독립된 요청으로 실행합니다.
- 검색 결과와 찜 목록은 10권씩 표시합니다. 검색 결과의 이동 가능한 페이지는 API의 리턴값을 따릅니다.
- 검색 결과와 찜 목록에서 책 소개, 정가, 할인 가격을 펼쳐 볼 수 있습니다. 구매하기는 API가 제공하는 책 페이지를 새 탭에서 엽니다.
- 찜한 도서는 저장 당시 데이터를 브라우저에 보관합니다. 책 표지는 lazy-loading 합니다.

## 강조하고 싶은 기능

- **최근 검색어 재사용** — 최근 검색어를 최대 8개까지 저장합니다. 검색창에 포커스를 준 상태에서 위/아래 방향키로 최근 검색어를 선택하고 Enter를 누르면, 선택한 검색어가 입력창에 채워지면서 바로 검색됩니다. 검색 기록은 개별 삭제할 수 있습니다.
- **검색에서 찜까지** — 일반 검색이나 상세검색으로 책을 찾고, 결과에서 책 소개와 가격을 펼쳐 본 뒤 표지의 하트로 찜할 수 있습니다. 찜한 책은 브라우저를 다시 열어도 남으며, 검색 결과와 찜 목록에서 동일한 도서 행 컴포넌트를 사용합니다.
- **10권씩 조회하고 결과 캐싱** — React Query가 검색어, 검색 조건, 페이지별로 결과를 캐시합니다. 조회 후 60초 안에 같은 검색어·조건·페이지를 다시 열면 추가 API 요청 없이 캐시된 결과를 표시합니다.

## 참고

- `app/books-app.tsx`는 검색어가 입력되기 전에는 검색 쿼리를 실행하지 않고, 브라우저 창에 포커스가 돌아올 때 자동으로 다시 조회하지 않으며 `app/api/books/route.ts`는 검색 결과를 한 번에 10권씩 요청합니다.
- `app/api/books-client.ts`는 React Query의 취소 신호를 `fetch`에 전달합니다. `app/book-row.tsx`는 책 표지에 `loading='lazy'`를 적용합니다.
